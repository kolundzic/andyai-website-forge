# Generated Site Contract

Required root files: `README.md`, `package.json`, `next.config.js`, `tsconfig.json`, `next-env.d.ts`.

Required app files: `app/layout.tsx`, `app/page.tsx`, `app/globals.css`.

Required routes in PACK2: `/`, `/about`, `/contact`, `/presentation`, `/projects`, `/signals`.

Required evidence: `docs/SITE_GENERATION_EVIDENCE.md`.

Generated sites must not contain `.env`, `.env.local`, `.next`, `node_modules`, database credentials, auth configuration, client uploads, or runtime AI provider keys.

The blueprint must define `site_slug`, `site_title`, `site_subtitle`, `domain_direction`, `owner`, `routes`, and `keywords`.
