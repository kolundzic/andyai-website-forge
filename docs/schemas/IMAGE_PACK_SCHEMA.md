# Image Pack Schema

## Purpose

The Image Pack defines the visual assets needed by a website.

## Required Fields

```json
{
  "images": [
    {
      "id": "hero-visual",
      "filename": "hero-visual.png",
      "purpose": "Homepage hero visual",
      "route": "/",
      "aspect_ratio": "16:9",
      "alt_text": "Clean visual explanation of the project",
      "status": "needed | ready | approved"
    }
  ]
}
```

## Suggested Image Types

- hero image
- strategy visual
- governance visual
- ecosystem visual
- artifact visual
- visual canon diagram
- mobile/social version

## Rule

Images must explain, not decorate.
