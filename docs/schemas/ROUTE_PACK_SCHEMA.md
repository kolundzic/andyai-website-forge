# Route Pack Schema

## Purpose

The Route Pack defines required and optional website pages.

## Recommended Base Routes

```json
{
  "required_routes": [
    "/",
    "/about",
    "/contact"
  ],
  "recommended_routes": [
    "/presentation",
    "/projects",
    "/signals",
    "/visual-canon",
    "/visual-identity"
  ],
  "optional_routes": [
    "/services",
    "/use-cases",
    "/pilot",
    "/resources"
  ]
}
```

## Route Rule

A route should exist only if it has a clear public purpose.
