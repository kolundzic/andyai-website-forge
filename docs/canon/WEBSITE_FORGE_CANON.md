# 🅰️ Website Forge Canon

## Core Canon

A website is not only pages.

A website is a public artifact system:

```text
Story → Structure → Visuals → Proof → Deployment → Trust
```

AndyAI Website Forge exists to turn serious ideas into serious public websites through a repeatable, safe, verified production flow.

## Main Formula

```text
One verified website pattern
+ one content pack
+ one image pack
+ one domain
+ one TAP-TAP strike
= new public website
```

## Human Role

Website Forge does not replace the human.

The human provides:

- judgment
- taste
- purpose
- approval
- final meaning
- public responsibility

Website Forge provides:

- structure
- repeatability
- safety boundaries
- QA discipline
- release evidence
- production speed

## Design Rule

Website Forge must produce websites that are:

- clear
- useful
- trustworthy
- visually readable
- structurally consistent
- safe to publish
- easy to explain
- easy to verify

## AndyAI Relationship

`andyai.ai` explains the AndyAI ecosystem.

`forge.andyai.ai` produces new websites through AndyAI method.

Main Site says what AndyAI is.
Website Forge makes new public artifacts.

## Public Artifact Standard

Every forged website should include:

1. clear identity
2. strong homepage story
3. visible proof or explanation layer
4. clean navigation
5. visual rhythm
6. readable content blocks
7. route QA
8. image QA
9. deployment evidence
10. human-approved final output

## Canon Sentence

Website Forge is not random site generation.
It is governed public artifact production.
