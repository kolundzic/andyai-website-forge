# 🤜💥 PACK2 — Site Template Generator Foundation

PACK2 moves AndyAI Website Forge from a documented foundation into the first controlled local generator skeleton.

It does **not** create a SaaS product. It does **not** deploy automatically. It does **not** touch `andyai-main-site`.

```text
Blueprint JSON → generated site scaffold → generated-site verification → evidence
```

## Canon

```text
Idea → Blueprint → Site Scaffold → Local QA → Evidence → Future GitHub/Vercel path
```

The generated site is intentionally minimal. The goal is controlled repeatability.

## Scope

- Generator plan and operator guide
- Generated-site contract
- Example generated-site blueprint
- Real local scaffold generator
- Generated-site verifier
- PACK2 checker
- PACK2 evidence

## Safety boundary

No Supabase. No auth. No database. No monetization. No client data. No runtime AI calls. No production deployment automation. No modification of `andyai-main-site`.
